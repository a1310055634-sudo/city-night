# 雪夜城市 v3.0 · 三渲二微缩城（有人生活的雪夜城）

单文件 Three.js 三渲二日式雪夜城市。**V1（20 轮）建城 → V2（20 轮）赋予生命与交互 → V3（20 轮）让城市透出「住着人」的气息**。2026-10-04 收官，共 60 轮。双击 `city-night.html` 即玩。

治愈而孤独的雪夜——街猫蜷在暖帘边、屋台蒸汽被风吹斜、深夜屋台亮到两点、神社雪灯次第亮起、清晨第一缕光里猫开始走街。**没有人，但处处是人的痕迹**。

## 这座城里有什么

- **5×5 街区 / 200m**：原点便利店（ひかりマート，橱窗内可见货架与关东煮）、32 间营业中商铺、16 栋公寓（晾衣杆上有衣服在风里摆）、2 霓虹区、2 公园、ほしみ駅、40m 星見タワー（塔身泛光）、穿城河 + 星見橋
- **生灵的痕迹**：5 只街猫各有领地与状态机（巡游/端坐/舔毛/蜷睡，雪天找暖点、雷雨躲藏，深夜 2-4 点最活跃）
- **深夜屋台**：暖帘微摆、红灯笼、蒸锅蒸汽随风斜；营业 18-2 点，2-7 点收摊
- **窗内生活光影**：31 扇窗有独立生活层——电视蓝闪换台、暖灯呼吸、窗帘开合、绿植微摆（**没有人影**，只有生活的光）；深夜渐灭至 0.1
- **神社雪灯祭**：朱红鸟居、参道石灯笼小径 ×6（注连绳与火苗昼灭）、本殿垂帘、雪松林围合
- **城市作息**：22 点起打烊（卷帘落下、招牌熄灭，便利店 24h 例外）、清晨 7-9 点重开、循环巴士停靠、红绿灯相位错峰、出租车混入车流、凌晨 2-4 点全城最静
- **天气的物理**：晴夜银河与流星、融雪冰柱（晴昼融化/夜雪重冻，会真的坠落）、雪的形态随风场在鹅毛与细雪之间滞回切换
- **声音**：神社风铃、猫叫、远犬吠、列车汽笛、时钟报时、凌晨底噪
- **收束**：拍照模式下的景深 + 胶片颗粒 + 暖冷分级；夜里的河上烟花（含水中倒影）

## 技术栈

Three.js r160（CDN importmap，零构建）；MeshToonMaterial + BackSide 描边壳 + UnrealBloom 三渲二；程序化 Canvas 全贴图（日文 font: Yu Gothic/Meiryo）；InstancedMesh / mergeGeometries 合并；Raycaster 拾取（过滤 Sprite，隐形盒池）；WebAudio 全程序化音景（零音频资产，默认静音）；全局风场 uniform；L0-L3 自动降档分级（`__perfLevel()` 可查）；**无外部图片/模型/音频资产**。

**性能**：draw calls 从 V2 收官 7663（远景 205m / L0 口径）经 V3 五阶段增量后收敛见账本决算表；无头软渲染 fps ≥30 为参考值，真机表现由用户验收。

**验收工具**：`shots\scan.mjs` 一键扫描器（三态 ×8 视角 + V3 扩展 62 张），`shots\` 内 500+ 张历史截图只增不删。
